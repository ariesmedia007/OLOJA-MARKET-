# OLOJA — Marketplace MVP

OLOJA is a mobile-friendly marketplace prototype for buying and selling in Nigeria.

## Current MVP
- Marketplace home page
- Search + category + location filters
- Listing detail pages
- Save/favorite listings
- Post listings
- Seller dashboard on the same device
- Delete your own prototype listings
- Email contact flow using ariesmedia007@gmail.com
- Responsive/PWA-ready structure
- LocalStorage persistence

## Important
This version is a front-end prototype. Listings are stored only in the browser/device. It is NOT yet a public multi-user marketplace.

## Quick test
Open `index.html` in a modern browser. For full PWA behavior, serve the folder from a local/static web server rather than opening it directly as a file.
